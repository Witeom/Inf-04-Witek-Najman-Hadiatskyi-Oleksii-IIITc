# Test cases

1. Administrator loguje sie danymi admin/password - dostep do panelu i funkcji administratora.
2. Uzytkownik loguje sie danymi jan/password - dostep do panelu bez operacji administratora.
3. Niepoprawne haslo - brak zalogowania i komunikat o bledzie.
4. Wyszukiwanie nazwy zasobu - widoczna tylko pasujaca pozycja.
5. Filtr kategorii - widoczne zasoby tylko z wybrana categoria.
6. Administrator dodaje zasob - nowa pozycja pojawia sie w katalogu.
7. Administrator wypozycza dostepny zasob - zmienia sie status na wypozyczony.
8. Administrator zwraca zasob - zmienia sie status na dostepny.
9. Uzytkownik dodaje zgloszenie - ticket pojawia sie na liscie.
10. Administrator zamyka zgloszenie - status zmienia sie na zamkniety.
